## Direction

`yukishinobi.dev` is the landing page for my product work, server engineering, developer tooling and selected experiments.

The design follows the same identity as my GitHub profile: dark graphite, silver typography, muted crimson accents, restrained motion and dense-but-readable project cards.

## Current build

- responsive landing page
- selected project cards
- server/product engineering positioning
- project principles section
- lightweight intersection animations
- no framework or build step
- mobile layout

## Run locally

Open `index.html`, or serve the folder with any static server.

```bash
npx serve .
```

## Why no framework yet?

The first version is intentionally static. A personal site should not need a large runtime just to communicate who I am and what I build. I can add data-driven project loading, a contact backend or deployment integrations when they are actually useful.
